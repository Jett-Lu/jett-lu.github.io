# Jett Lu

Personal portfolio website built with HTML, CSS, and JavaScript.  
Hosted via GitHub Pages at: [https://jett-lu.github.io](https://jett-lu.github.io)

## Features

- Responsive single-page layout  
- JavaScript-based interactive game  
- Resume and contact links

## Usage

To view the site locally:
```bash
git clone https://github.com/Jett-Lu/jett-lu.github.io.git
cd jett-lu.github.io
open index.html  # or open in your preferred browser
```
